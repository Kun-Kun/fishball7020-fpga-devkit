A buildable firmware for this radio

A Zynq XC7Z020 and an AD9361 sold under several names, reverse-engineered far enough that you can build every file on the SD card from source — and then put your own logic in the radio's datapath.

As of v1.7, rebuilding this firmware needs nothing from AMD. The boot loader is compiled from AMD's public embeddedsw with an ordinary gcc-arm-none-eabi, and bootgen is built from AMD's Apache‑2.0 source. Vivado is required only to synthesise the bitstream — and if you start from a released hardware platform, not even installed.

Four commands

# run from: the repo root
./devkit doctor     # can this machine build? answers in a second
./devkit setup      # fetch sources, embeddedsw and bootgen; apply patches
./devkit build      # seven stages, ~20 min
./devkit flash      # onto the running board, backed up and md5-verified

./devkit verify --board is the one that proves the board is running what you built. Flashing goes over the network through the SD partition — never DFU, which on this board has bricked units.

./devkit ssh-key is worth running before any of it: it makes a key used for this board and nothing else, installs it, and gives you ssh fishball instead of the published root password. It checks the result with BatchMode, which cannot fall back to a password — so a pass means the key really did the work.

Use firmware-modern unless you specifically want the factory reconstruction. The card dual-boots: if the Debian kernel fails to load, U‑Boot falls back to the Buildroot ramdisk, so a bad write does not cost you a card reader.

Where the written documentation lives

Everything under docs/ is Markdown, and GitHub renders Markdown properly while this site would hand you the raw file — so the prose lives in the repository and in the wiki. This site exists for the things that have to be web pages.

The ones worth knowing about: building, flashing (including how to recover a board that will not boot), transmitter safety — read that one before anything radiates, because this board has a power amplifier — the block design IP by IP, and what one board actually measures.

Built against Vivado 2022.2 on Ubuntu 22.04 — and, since v1.7, nothing else from AMD. Every measured number here and in the course came off one board, with its conditions attached. The firmware is GPL‑2.0; AMD's embeddedsw is MIT and its bootgen Apache‑2.0.
